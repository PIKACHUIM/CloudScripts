# Internationalization (i18n)

PIKA SH 支持多语言，根据系统语言环境自动切换。

## 语言检测规则

优先级（从高到低）：
1. `PIKA_LANG` 环境变量
2. `/etc/pika-sh/config` 中的 `lang` 配置
3. `LC_ALL` 环境变量
4. `LC_MESSAGES` 环境变量
5. `LANG` 环境变量
6. 默认：`zh_CN`

## 支持的语言

| 语言 | 代码 | 状态 |
|------|------|------|
| Chinese (Simplified) | `zh_CN` | 完整（兜底语言） |
| English (US) | `en_US` | 完整 |

## 切换语言

```bash
# 命令行参数
bash Menu.sh --lang=en_US

# 环境变量
export PIKA_LANG=en_US
bash Menu.sh

# 菜单内切换（System Tools > Language）
```

## 添加新语言

1. 复制 `Linux/I18n/zh_CN.sh` 为 `<locale>.sh`
2. 翻译每个值的右侧部分（保持键不变）
3. 系统会根据 `$LANG` 的前两位自动匹配文件

示例（添加日语 `Linux/I18n/ja_JP.sh`）：
```bash
T["app.name"]="PIKA SH - サーバースクリプトツールボックス"
T["menu.main"]="メインメニュー"
# ...
```

## 缺失键处理

如果目标语言包缺少某个键，系统会自动回退到 `zh_CN` 的值，而不会显示空白。

## 语言包 CI 检查

GitHub Actions 会自动检查：
- 语言包语法正确性
- en_US 的键集合不超过 zh_CN（即所有键都有兜底翻译）
